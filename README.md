# shmuelie-skills

Public GitHub Copilot CLI skills, grouped into focused plugins.

Install everything:

```text
copilot plugin install shmuelie/shmuelie-skills
```

Or install a focused plugin:

```text
copilot plugin marketplace add shmuelie/shmuelie-skills
copilot plugin install shmuelie-dotnet@shmuelie-skills
```

## Plugins

| Plugin | Focus |
|---|---|
| [`shmuelie-copilot`](docs/plugins.md#shmuelie-copilot) | Copilot sessions, reports, playbooks, and plugin authoring |
| [`shmuelie-devenv`](docs/plugins.md#shmuelie-devenv) | PowerShell, shell, deployment, profiles, CI, local MCP servers, and threat-model files |
| [`shmuelie-authoring`](docs/plugins.md#shmuelie-authoring) | RFC-style specifications, readability, project proposals, and artwork |
| [`shmuelie-dotnet`](docs/plugins.md#shmuelie-dotnet) | .NET, API clients, interop, diagnostics, DuckDB, Roslyn, WinUI 3, MSIX, and assets |
| [`shmuelie-systems`](docs/plugins.md#shmuelie-systems) | Embedded C++, homelab infrastructure, and AI accelerators |
| [`shmuelie-typescript`](docs/plugins.md#shmuelie-typescript) | Reliable TypeScript and Node.js command-line applications |
